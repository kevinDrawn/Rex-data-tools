# Rex 데이터 뷰어

Windows에서 Dear ImGui와 ImPlot으로 실행하는 측정 데이터 도구입니다.
기존 C 패킷 해석·CSV 저장 모듈을 C++ GUI에서 호출합니다.

## 빌드와 실행

필요한 도구는 Git, CMake 3.20 이상, Visual Studio의 C++ 데스크톱 개발 도구와 Windows SDK입니다.
첫 구성 시 ImGui와 ImPlot을 인터넷에서 내려받습니다. 이후 소스는 `build/_deps/`에 유지됩니다.
프로젝트 루트의 PowerShell에서 실행합니다.

```powershell
cmake -S . -B build -G "Visual Studio 16 2019" -A x64
cmake --build build --config Release --parallel 4
ctest --test-dir build -C Release --output-on-failure
.\build\Release\rex_viewer.exe
```

Visual Studio 2022를 사용하면 생성기 이름을 `Visual Studio 17 2022`로 바꿉니다.
생성기를 바꿀 때는 기존 빌드와 다른 폴더(예: `build-vs2022`)를 사용하세요.
이 환경에서 사용한 CMake 경로는 `C:\ncs\toolchains\b8b84efebd\opt\bin\cmake.exe`입니다.
PATH에 CMake가 없다면 해당 경로를 `& '전체 경로'` 형태로 호출할 수 있습니다.

뷰어 없이 기존 콘솔 로거와 테스트만 빌드하려면 구성 시 `-DREX_BUILD_VIEWER=OFF`를 붙입니다.
콘솔 로거 실행 파일도 `build/Release/rex_logger.exe`로 함께 생성됩니다.

## 파일 탐색

1. 시작하면 실제 측정과 구별되는 60초 샘플 데이터가 표시됩니다.
2. `CSV 열기`로 로거가 생성한 파일을 선택합니다. 한글 경로를 지원합니다.
3. 왼쪽에서 변수를 선택하고 시작 시각과 표시 길이를 초 단위로 입력합니다.
4. 아래 `전체 기록 위치` 막대를 좌우로 드래그하여 같은 길이의 시간 창을 이동합니다.
5. 그래프를 왼쪽 드래그하거나 휠로 확대·축소하면 다른 그래프의 시간축에도 반영됩니다.
6. `기록 재생`은 저장된 파일의 시간 창을 이동합니다. MCU 신호를 흉내 내어 수신하는 기능은 아닙니다.

각도·토크·EMG는 단위별 그래프로 나눠 표시합니다. 기타 변수에는 `actual_time_ms`,
`drift_ms` 등이 들어갑니다. `자동 Y축`을 끄면 Y축 범위를 직접 조절할 수 있습니다.
단위가 다른 기타 변수는 동시에 선택할 때 축 해석에 유의하세요.

현재 CSV 입력 조건은 다음과 같습니다.

- UTF-8 또는 ASCII 열 이름과 쉼표로 구분한 숫자 데이터
- 필수 열 `time_ms`; 중복 없이 증가하는 유한한 시간값
- 모든 열에 유한한 숫자가 있어야 하며 따옴표로 감싼 필드는 지원하지 않음
- 최대 200만 행, 최대 64개 변수, 숫자 데이터 256 MiB 중 먼저 도달하는 한도
- UTF-8 BOM, Windows 줄바꿈, 열 순서 변경 지원

한도는 메모리에 담는 숫자 크기 기준이며 전체 프로세스 메모리는 벡터 여유 공간·문자열·그림
버퍼 때문에 더 클 수 있습니다. 긴 기록은 향후 디스크 인덱스 기반 읽기로 확장할 수 있습니다.
파일은 별도 작업에서 읽고, 실패하면 이전 데이터와 오류 설명을 유지합니다.

## MCU 실시간 수신과 저장

1. 기존 콘솔 로거 등 같은 포트를 쓰는 프로그램을 닫습니다.
2. `COM7` 형식의 포트와 통신 속도(기본 460800)를 입력하고 `MCU 연결`을 누릅니다.
3. 보드가 현재 프로토콜의 364바이트 프레임을 보내면 그래프가 갱신됩니다.
4. `CSV 저장`을 켜면 그 시점부터 모든 수신 샘플을 저장합니다.
5. `최신 구간 추적`을 끄거나 그래프를 이동하면 현재 버퍼를 탐색할 수 있습니다.
6. `CSV 저장`을 끄거나 연결을 해제하거나 창을 닫으면 파일을 마무리합니다.

화면에는 최근 60초만 유지합니다. 전체 데이터는 실행 파일 옆의 `logging/`에
`rex_live_날짜_시각_밀리초.csv`로 저장합니다. 저장 버튼과 실제 저장 상태에는
수신 작업 주기만큼의 짧은 지연이 있을 수 있으므로 상태와 파일 경로를 확인하세요.

UART 읽기·해석·파일 쓰기는 전용 작업 스레드에서 실행합니다. GUI에는 최대 200배치의
표시용 큐로 전달합니다. 화면이 느려 큐가 차면 표시용 배치만 제거하고 누락 횟수를 표시합니다.
이 구조도 디스크나 운영체제 전체의 지연에 대한 무손실을 보장하지는 않습니다.
쓰기 오류나 연결 오류가 발생하면 수신을 중지하고 메시지를 표시합니다.
수신이 없을 때도 약 20 ms의 읽기 제한 시간을 두므로 연결 해제가 가능합니다.

## 시간과 검증 범위

표시·CSV의 기본 시간은 수신한 샘플 수로 계산합니다. 표시 큐 누락은 원래 수신 샘플 번호로
유지하지만, 보드나 UART에서 잃은 프레임 수는 현재 프로토콜로 알 수 없습니다.
체크섬·순번·장치 시각 추가는 펌웨어와 함께 진행해야 합니다.
각도와 토크 단위는 기존 환산식을 유지했으며 펌웨어 정의 확인이 필요합니다.

자동 테스트는 정수 경계값, 전체 채널, CSV 저장·읽기 왕복, 잘못된 입력, 피크 보존,
분할 수신·잘못된 길이·헤더 재동기화를 검사합니다. 실제 보드로 수신율과 연속 기록을
검증하는 시험은 별도로 필요합니다.

다음 명령은 창을 숨긴 채 네 프레임을 렌더링한 후 종료하고 현재 폴더에
`rex_viewer_preview.bmp`를 만듭니다. 장치와 한글 글꼴 초기화도 실행합니다.

```powershell
.\build\Release\rex_viewer.exe --smoke-test
```

## 파일별 역할과 의존성

- `main_win32.cpp`: 창, 한글 글꼴, DirectX 11 초기화와 종료
- `viewer_ui.h/.cpp`: 변수 선택, 그래프, 타임라인, 연결·저장 제어
- `log_data.h/.cpp`: CSV 읽기, 샘플 데이터, 실시간 배치 변환, 피크 보존 집계
- `../acquisition/frame_parser.h/.cpp`: 수신 바이트를 프레임으로 조립
- `../acquisition/live_session.h/.cpp`: UART 작업 스레드, 파일 저장, 표시 큐

ImGui는 `v1.91.9b`, ImPlot은 `v0.17` 커밋으로 고정했습니다.
빌드 폴더에는 각 의존성의 원본 LICENSE가 유지됩니다. 배포 시 해당 고지문도 포함하세요.

- [Dear ImGui 공식 저장소](https://github.com/ocornut/imgui)
- [ImPlot 공식 저장소](https://github.com/epezent/implot)

그래프의 이미지 내보내기, 분석, 선택 구간 파일 내보내기는 아직 구현하지 않았습니다.
