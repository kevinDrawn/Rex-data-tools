# Functional gait metric exports

Run in order:
1. Paw Clearance/exec_export_paw_clearance_metrics.m
2. Dorsiflexion angle/exec_collect_peak_swing_dorsiflexion.m
3. Paw Clearance/exec_plot_functional_gait_metrics.m

Default output: Paw_clearance/_functional_metrics. Every MAT uses variable `data`.
- paw_clearance_plot_data.mat: MeanTrajectoryPeakHeight, MeanPeakPawHeight,
  MeanTrajectoryVerticalExcursion, SwingStanceRatio, PerCycle, PerAnimalDetails,
  and RatTrajectories (selected source files, time masks, and phase curves).
- peak_swing_dorsiflexion_plot_data.mat: RatMeans, RatSDs, CycleCounts,
  GroupSummary, PerSwing, PerAnimalDetails.
- Additional Baseline/IE/IR/LE/LR MAT files contain condition-level summaries.

Each numeric metric has RatIDs (rows), ConditionNames (columns), RatMeans,
RatSDs (within-rat cycle SD where defined), CycleCounts, GroupSummary, Conditions.
Group bars are unweighted rat means +/- sample SD across rats; dots are rat values.
Default paw plot is MeanTrajectoryPeakHeight (maximum of each rat-level mean
trajectory relative to a fixed mean stance-minimum offset). It is distinct from
MeanPeakPawHeight (mean of individual swing-maximum minus stance-minimum values).
Set PAW_METRIC='MeanPeakPawHeight' in the plotting exec to use cycle-peak means.
No per-cycle SD is defined for a single mean-trajectory peak; its RatSDs are NaN.
Only complete IC-to-IC cycles enter paw summaries, matching the mean trajectories;
this can differ from the older collector which included observed open swings.
Paw time_range.txt selection is honored independently for each recording.
Existing 15 Hz filtered trajectories are used; no extra filtering or IL-Y subtraction.
Multiple videos are pooled within rat/condition; legacy exports lacking IL are skipped.

Dorsiflexion is the minimum original Hall angle in each complete [TO, next IC) swing.
Lower Hall angle means greater dorsiflexion; values are not anatomical neutral angles.
The existing exp_data contains IE/IR/LE/LR only. Baseline is explicitly NaN/N=0.
BASELINE_META_PATH optionally accepts another exp_data MAT with the same schema
and cond='Baseline'; do not substitute mocap angles into the Hall metric.
Hall events use stored aligned times and metadata analysis intervals. Paw clip-time
ranges must not be transferred to the Hall timeline without synchronization.
Dragging incidence requires explicit annotations and is not inferred from peak height.
No significance/equivalence claim is generated by these export scripts.

## Current figure layout
Vertical bars: paw height (Baseline/IE/IR/LE/LR), swing dorsiflexion (LE/LR),
and dragging incidence (LE/LR). Swing/stance ratio is not plotted.
The plotting exec creates _functional_metrics/dragging_counts.csv if absent.
Fill integer DraggingCount and TotalCycles per rat/condition; each numerator is
number of scored swing phases with dragging, not number of contact frames.
Pool counts across videos of the same rat/condition before entering the row.
Leave both blank for unscored data. Zero is a measured zero, not missing.
Rerun the plotting exec to update dragging_incidence_plot_data.mat and figures.
The template is never overwritten; unscored panels contain no invented bars/dots.
